ALIGN ELEVATION ROWS 3.4.3

This focused correction button addresses the upper-row issue directly.

The tool groups existing elevation rows from their current viewport box-bottom Y positions, not viewport centres. It then aligns each detected row independently. The upper row remains the upper row and the lower row remains the lower row.

Default alignment is Viewport bottoms. Increase Row Detection Tolerance if a visibly staggered upper row is incorrectly detected as several rows. Start with 80 mm.
